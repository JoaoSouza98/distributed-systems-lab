# Desafios

Abra um arquivo por desafio, com um identificador estável no nome, como `NNN-titulo.md`. Registre o estado do desafio, o problema, os requisitos e restrições conhecidos, as premissas e os critérios de conclusão.

Complete o registro com a proposta do participante, os argumentos relevantes da discussão e da revisão, os links para decisões e experimentos e uma retrospectiva curta. Consulte o [guia do laboratório](../GUIA_DO_LABORATORIO.md) para o fluxo completo.
