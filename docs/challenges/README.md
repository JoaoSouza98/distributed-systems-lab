# Desafios

Abra um arquivo por desafio, com um identificador estável no nome, como `NNN-titulo.md`. Registre o estado do desafio, o problema, a entrega incremental de valor, o escopo, os requisitos e restrições conhecidos, as premissas e os critérios de aceite.

Complete o registro com a proposta do participante, os argumentos relevantes da discussão e da revisão da entrega, os links para decisões e evidências de testes e experimentos e uma retrospectiva curta. No encerramento, registre o estado da solução, os riscos aceitos, as pendências e os aprendizados. Consulte o [guia do laboratório](../GUIA_DO_LABORATORIO.md) para o fluxo completo.
