# Registros de decisões arquiteturais

Use um arquivo por decisão relevante, como `NNN-titulo.md`. Inclua data, estado, desafio relacionado, contexto, alternativas avaliadas, decisão do participante, justificativa, consequências e condições para reavaliá-la.

Quando uma decisão for substituída, preserve seu conteúdo e indique o ADR que a substituiu. Vincule as evidências que influenciaram a decisão.
